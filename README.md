# tuning-mod-fg-wfg

On-demand Frame Generation engine for [Winlator Tuning](https://github.com/palazos/winlator-ludashi-tuning-5).

Install from the in-app **Tuning Modules** store. Native payload is published as `fg-wfg-module.zip` on Releases.

`engineSlot`: `frameGen` (conflicts with the other `fg-*` modules when selecting an active engine).
